# 30 проверок main по референсам — 28 ноября 2026

Задача: проверить фактический `main`, найти и исправить расхождения, особенно связанные с неудачным iPhone → Windows аудиотестом. Это **не** утверждение о готовности AirPlay. Перед каждым пунктом сверить, не исправлен ли он уже; при дублировании с [D01–D30](AGENT-BATCH-20261128.md) объединить работу и записать результат в обе строки, не создавать копию теста. Выполнять последовательно в `agent/integration` по [общим правилам](AGENT-TASKS.md), указывая в строке владельца, SHA, источник/ревизию/функцию, подтверждённый факт, команды и оставшиеся ограничения.

**Источники:** S — [shairport-sync 5.5.2](https://github.com/mikebrady/shairport-sync/tree/5.5.2); U — [UxPlay 534e2cc0](https://github.com/FDH2/UxPlay/tree/534e2cc0e558d6c94bcc66964f8fc13ad73a6cdc); O — [OwnTone 612d6b3c](https://github.com/owntone/owntone-server/tree/612d6b3cf34ae38bb71b6edfcd69fd7afe6ab25c); P — [pyatv b277a4c8](https://github.com/postlund/pyatv/tree/b277a4c8222ecdcbaab8a24e3e713ca44765adb4); M — [doubletake 5e2f1cbe](https://github.com/omarroth/doubletake/tree/5e2f1cbe3e1070bcefec8e549c7baf884727bc00); T — локальный снимок Станции `a1aefc790522f271114c80c081a8e07cd6fe1e86`, см. [инвентаризацию](STATION-CORE-INVENTORY-20261126.md). Уточнять путь/функцию и лицензию для каждого вывода. Использовать документированные факты и независимые векторы; код не копировать. Название поля не доказывает его семантику.

Вчера iPhone видел `AirPlay-Win`, transient pairing проходил, но в одном прогоне audio SETUP отклонён проверкой `shk`, в другом сессия закрылась после NTP SETUP. **Причина не установлена**. Программные тесты, сетевой mock и физические проверки указывать отдельно. До подтверждения не объявлять поддержку устройства или исправление звука. Не работать параллельно с координатором над dual PTP и четырьмя файловыми профилями; по этим темам готовить независимые векторы и аудит.
