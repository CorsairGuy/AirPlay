# Чтение SHM NQPTP: ABI10/ABI11

Ветка `feat/nqptp-shm-reader`, база — `main` `b612eb4`, 2026-11-26.
Задача **C** из [AGENT-TASKS](AGENT-TASKS.md) (итоги инвентаризации — ветка
`feat/station-core-inventory`, `STATION-CORE-INVENTORY-20261126.md`).

## Что было не так

В `main` не было ни одного `nqptp`-упоминания: из переноса Станции остался
только контракт квалификатора (`clock::external`, `raw_correlation`,
`external_media`), но не было чтения того, что публикует демон. Без него
переход «приёмник остаётся Shairport, отправка идёт с общих часов» невозможен:
ядро умело квалифицировать наблюдение, но не получало его.

## Что сделано

`crates/clock/src/nqptp.rs` — чистый декодер и маркер готовности, без сокетов,
mmap и команд демону:

- Версия структуры — native-endian `u16` в начале буфера.
- Две копии записи (`ABI10` — 4 поля, `ABI11` — 5), сравниваются поле за
  полем: расхождение = torn/half-published write и явная ошибка `Torn`, а не
  усреднение или догадка.
- Порядок полей: `master_clock_id`, `local_time`, `local_to_master_time_offset`,
  `clock_change_offset` (только `ABI11`), `master_clock_start_time`.
- `clock_id == 0` — `Unpublished`: демон ещё не публикует часы.
- Неизвестная версия, короткий буфер, обрезанный `ABI11` под видом `ABI10` —
  отказ; лишние байты после пары копий игнорируются.
- `Sample::observation()` отдаёт `clock::external::Snapshot` без пересчёта
  полей, чтобы идентичность и эпоха не подменялись по дороге.
- `read_path` (только Unix) читает файл read-only; согласованность даёт
  двойная копия, а не атомарность чтения — сорванную запись владелец
  повторяет сам.

Источник wire-фактов: закреплённый срез Станции `a1aefc79`,
`src/airplay_sender/src/ptp.rs` (приватный репозиторий; взяты только порядок
полей и смещения, код не копировался). Там же указано, что `ABI11` добавляет
`clock_change_offset` перед `master_clock_start_time`, а патченный
sender-master переписывает стартовый маркер на keepalive — поэтому
`external::StartMarker` остаётся политикой владельца, а не выводится из байтов.

## Что осознанно не сделано

- **Аттестации нет.** Декодер не доказывает, что демон пропатчен под
  grandmaster-роль: версия структуры — единственный готовый маркер, и в отчёте
  это названо маркером, а не доказательством. Проверка бинарника/роли — задача
  **D**.
- **Свежести и корреляции нет.** `local_time` из SHM — сырое монотонное время
  демона; пересчёт в `Instant`-эпоху ядра требует измеренной корреляции
  (`raw_correlation`) и остаётся в **D/E**. Подставлять RAW-наносекунды в
  `InstantSource` запрещено комментарием самого `InstantSource`.
- **Живого чтения на устройстве не было**: в окружении нет ни NQPTP, ни
  Station. Тесты — независимые фикстуры, построенные по документированным
  смещениям, а не захваченный файл.
- Команды демону (`/airplay-sender M ...`, keepalive 4 с, timeout 15 с) не
  переносились: это владение процессом на стороне приложения/Станции.

## Проверки

```
cargo test --offline -p clock --lib        -> 73 passed (7 из них — nqptp)
cargo clippy --offline --all-targets -p clock -- -D warnings  -> чисто
cargo fmt --check -p clock                 -> чисто
```

Тесты: точное соответствие полей `ABI10` и `ABI11` (включая место
`clock_change_offset` и последний стартовый маркер); разные копии — `Torn`;
нулевой clock ID — `Unpublished`; неизвестная версия, короткий и обрезанный
буферы — отказ; хвостовые байты игнорируются; native-endianness зафиксирована
явно; из декодированной записи собирается `external::Selection`, которую
принимает `Qualifier` (роль всё равно аттестует владелец).

## Ограничения

- Смещения и порядок полей взяты из одного референса (срез Станции). Второго
  независимого описания ABI в окружении нет; живой файл не читался.
- `read_path` не проверяет, что путь не подменён (симлинк, чужой файл) — это
  ответственность владельца демона.
- Windows-сборка `read_path` не содержит: SHM-путь там не применяется.
