# Выбор и ограничение задержки аудио

Ветка `feat/tx-latency` от `origin/main` (`847fe38`). В `main` не влита.

## Что проверено

- `SessionConfig.latency_frames` задаёт желаемую задержку 44,1 кГц; SETUP
  объявляет `latencyMin`/`latencyMax` из новой политики, а не жёсткие
  `11_025`/`88_200`.
- Ответ SETUP с `latencyMin`/`latencyMax` разбирается и проверяется:
  `min > max` отклоняется; нулевой минимум допустим, максимум ограничивается пересечением.
- Эффективная задержка — пересечение диапазона sender и приёмника; желаемая
  зажимается в него. Если пересечения нет, сессия не начинается
  (`no common latency range with receiver`).
- Для пакетизатора сохраняется `receiver_min` как render latency, поэтому
  RTP-таймстемпы по-прежнему учитывают минимальную задержку приёмника.
- `LatencyPolicy::pre_record_delay` — дополнительная пауза перед RECORD,
  ограниченная итоговой задержкой. До RECORD данные не отправляются, поэтому это не предзаполнение. Политика публичная и задаётся вызывающим
  через `SessionConfig.latency_policy`.

## Тесты

`crates/media/src/tx/session.rs`, модуль `latency_tests`:
- быстрый приёмник (`max 11025`) зажимает 22050 до 11025, медленный
  (`min 44100`) поднимает до 44100, точное значение сохраняется;
- непересекающийся диапазон, `min > max` и узкая политика отклоняются;
- начальный буфер обрезается до длительности итоговой задержки;
- невалидная политика отклоняется до подключения (`SessionConfig::validate`).

`cargo test -p media` — 77 тестов, все прошли, включая существующие
PTP-тесты (движок не менялся).

## Ограничения

- **Это расчётная задержка, а не измеренная акустическая.** Реальных
  измерений задержки на Apple TV/колонках не было.
- Смена трека не добавляет отдельную паузу: новый трек в текущем API — это
  новые метаданные в той же сессии; `pre_record_delay` применяется при старте
  сессии. Для смены трека с новым SETUP используется та же политика.
- NTP/PTP-движок не менялся.
- Значения `latencyMin/latencyMax` взяты из ответа SETUP; другие источники
  (`/info`) в этой задаче не подключены.
