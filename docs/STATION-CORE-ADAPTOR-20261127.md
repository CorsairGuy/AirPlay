# Station adapter: синтетический контракт источника

Срез Станции `a1aefc79` и его `docs/CORE_SENDER_ADAPTOR.md` на 27.11.2026 недоступны
(HTTP 404), поэтому эта заметка опирается на локальную инвентаризацию
[STATION-CORE-GAPS](STATION-CORE-GAPS-20261126.md) и на код ядра, а не на
внешний документ. Код Станции не копировался.

## Что проверено адаптером

`services/media/tests/station_adapter.rs` — синтетический адаптер над
`media::tx::continuous::Timeline` (без Quasar, ALSA, файлов и демонов Станции):

| Ситuation | Контракт ядра | Что видно |
| --- | --- | --- |
| pause | `Timeline::pause`, `Step::Frame` с нулевым PCM | тишина идёт по расписанию, кадр источника не потребляется |
| resume | `Timeline::resume` | отложенный кадр отдаётся со следущим `frame_index`, медиашкала не сбрасывается |
| seek | `invalidate_source` + новая генерация | старие кадры получают `DiscardStale`, новая генерация принимется без сброса времени |
| EOF | grace 40 мс, затен нулевым PCM | тишина не пересоздаётся, `epoch` тот же |
| необъявленная генерация | ошибка | не тихий пропуск и не автоadvance |

## Таблица недостающих контрактов

Актуальная таблица — в [STATION-CORE-GAPS](STATION-CORE-GAPS-20261126.md):
G1 (маркер перемотки в медиапотоке), G2 (маркер авто-спаривания при импорте),
G3 (активация PTP-группы во frontend). Новых контрактов адаптер не добавляет:
он проверяет только уже существующую политику `continuous`.
