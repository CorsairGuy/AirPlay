# PICKER-DEVICE-CLASSES.md
Классы устройств AirPlay-пикера: model-маркеры, классификация, иконки.
Сопровождает накопитель PLAN-ADDENDUM-v11.1 (L-63, L-69, L-84, L-90, сводная секция «Пикер»).
Правило пополнения: каждая строка — уровнем подтверждения (спека / дампы / обзоры / гипотеза).

---

## Ключевой факт об иконках

Иконку в пикере рисует САМ iPhone (локально, по классу устройства) — приёмник иконку не передаёт.
Следствие: подмена model в mDNS-анонсе меняет и классификацию, и иконку — пикер отрисует то,
что считает нужным для объявленного класса. Механизм выбора иконки для Unknown-подтипов и
видео-классов публично не реверснут (открытый вопрос; см. патч 16).

## Не-классы (чтобы не терять время)

- iPad приёмником не является никогда (никаких model iPad* в пикере нет).
- Apple Watch, Vision Pro — приёмников нет.

## Открытые вопросы (пополняется)

1. Механизм иконки ТВ при Unknown-подтипе: как smart-TV (не-Apple model) получают ТВ-иконку — по video-фичам в features или по другому полю? Не реверснуто.
2. Точные model-строки Mac-приёмника в хозяйстве — закрыть дампом на шаге 0 эталон-захвата (UxPlay -p2p на Mac).
3. Иконка приёмника в AWDL/P2P-секции пикера — отдельная проверка эксперимента L-100 (исход «а»).
