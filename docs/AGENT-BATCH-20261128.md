# 30 задач агенту — 28 ноября 2026

Очередь конкретизирует открытые задачи из [AGENT-TASKS](AGENT-TASKS.md), не объявляет их завершёнными. Выполнять **последовательно** в `agent/integration`, начиная с актуального `main`: перед каждой задачей сверить код и отметить владельца, затем в строке указать коммит, команды, результат и остающиеся критерии. Правила проверки референсов, авторства, слияния и недопущения выдуманной поддержки — в AGENT-TASKS. До начала проверить, не изменился ли код; выполненные или дублирующиеся пункты не переделывать, а отметить с доказательством.

Общие референсы: план [v12](AGENT-PLAN-AP12-20261112-v12.md); захват реальной Apple TV — [MIRRORING-AIRPLAY2-RESEARCH](MIRRORING-AIRPLAY2-RESEARCH.md); контракт Станции — [STATION-PIPELINE-CONTRACTS](STATION-PIPELINE-CONTRACTS-20261127.md), снимок `a1aefc790522f271114c80c081a8e07cd6fe1e86`; шифрование и медиапуть — [AIRPLAY-WIRE-SPEC](AIRPLAY-WIRE-SPEC.md); сессии — [SESSION_PROFILES](SESSION_PROFILES.md). Для внешнего референса указывать **точную ревизию, файл/функцию и wire-факт**, проверять лицензию; чужой код не копировать. Тесты должны проверять поведение, не реализацию. Аппаратные проверки не выдумывать.

Координатор отдельно доводит двойной PTP и Windows-профили. Не менять `services/timesync` и файлы `docs/profiles` параллельно; задачи PTP ниже относятся к независимому аудиту/векторам либо требуют отдельного согласования. Использовать только обезличенные fixtures и временные ключи.
