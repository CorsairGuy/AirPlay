# Передача работы — 26 ноября 2026

1. Изучить [текущее состояние](STATUS.md), [очередь агентов](AGENT-TASKS.md) и релевантные разделы [плана v12](AGENT-PLAN-AP12-20261112-v12.md). Перед работой проверить текущий `main`, ветки и рабочее дерево.
2. Продолжить ревью непринятых изменений агента: AP1 TX (`et`, timing, retransmit) сравнивать с текущей реализацией, не перезаписывая добавленные RSA и общие часы. Не считать совместимость доказанной только тестом своего mock.
3. Не включать без исправления восстановление долгой сессии по одному скачку RTP: запоздавший пакет может вызвать ложный сброс. Проверить смену эпохи и `played_through`.
4. В своей ветке фиксировать задачу и результаты в [AGENT-TASKS](AGENT-TASKS.md), указывать источники, ревизии и оставшиеся аппаратные проверки. Чужие ветки или рабочие деревья не удалять автоматически.

Политика проекта: код внешних референсов не копировать, подтверждать wire-факты; NQPTP не встраивать в ядро. Windows-приложение остаётся отдельным проектом. Старые истории доступны в Git и `history/`.
