# Security


## План v12: границы экспериментальных транспортов

Один владелец UDP319/320 на хосте; NQPTP и core PTP не запускаются конкурентно.
Hotspot/AWDL/nexmon — отдельное согласие на изменение сети/firmware и резервный доступ.
BLE-адреса/IP могут раскрывать идентификаторы: L-91 — непроверенный кандидат OBS;
не публиковать реальные MAC/IP/дампы без редактирования чувствительных данных.
Apple-код/декомпиляты не включаются; новые внешние источники — provenance-тег по §0.5 v12,
только идеи/структура/wire-факты, собственный код с нуля. AGPL/fdk-aac включение требует
отдельного решения. Это политика проекта, а не юридическое заключение.
